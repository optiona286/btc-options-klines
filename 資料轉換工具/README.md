# 資料轉換工具

需要 Node.js 20.3 以上，無須安裝套件。這個工具可隨 Git 專案下載到任何電腦使用。

1. 新資料 ZIP 直接放入 `G:\Mark Price Kline BTC` 的月份資料夾，工具會遞迴讀取，不用搬移檔案。預設來源設定在 `config.json` 的 `sourceDirectory`，換電腦或位置時修改此欄位即可。
2. 雙擊「手動轉換.cmd」立即轉換；或雙擊「自動監看.cmd」，保持視窗開啟，每 10 秒檢查並轉換新檔。按 Ctrl+C 或關閉視窗即可停止。
3. 轉換完成後，重新整理網頁。若要更新 GitHub Pages，手動提交並推送 `data` 變更；程式不會自動上傳。

檔名格式：`2026-10-07_BTC_USDT.OHLC.csv.zip`。每個 ZIP 必須有一個 CSV，欄位包含 `instrument_name,open_time,open,high,low,close`；時間為 UTC 毫秒，合約格式如 `BTC-10OCT26-65000-C-USDT`。ZIP 日期必須與 CSV 的 UTC 日期一致。相同日期只保留一個 ZIP。

每個日檔只更新該日及後兩日的到期日資料，因此每個到期日仍包含到期當天與前兩天。分鐘資料聚合為 1h：第一筆開、最高高、最低低、最後一筆收，成交量保持空值。既有其他日期資料保留，補檔或替換修正 ZIP 後會取代對應 UTC 日資料，不會重複累加。尚未收到的前兩天資料會保留缺日提示；想讓新到期日完整，請放入三個日檔。

首次執行直接以現有 data/manifest.json 為基準，已涵蓋的原始日期不會重新讀取或解壓縮。已有處理紀錄且大小、修改時間不變的 ZIP 也直接略過；新增檔或修改檔才讀取並核對 SHA-256。原始 ZIP 留在來源資料夾，`.state` 不會進 Git；工具不會刪除原始檔。自動監看需檔案至少穩定一輪且修改時間超過 10 秒，解壓失敗會留待下輪重試。只允許一個轉換程序同時執行。

也可以在專案根目錄使用：

```powershell
npm run convert
npm run watch-data
node "資料轉換工具/convert.js" --input "D:\新的原始資料"
node "資料轉換工具/convert.js" --force
```

`--force` 強制重新讀取指定輸入資料夾中的所有 ZIP。修正既有基準日期時，請將該日修正版 ZIP 放進單獨資料夾，使用 `node "資料轉換工具/convert.js" --input "D:\單日修正" --force`，避免強制重跑全部歷史檔。監看與手動模式第一次就會略過現有精簡資料已涵蓋的日期，只處理新增日期、缺日補檔，或本機有處理紀錄且已修改的檔案。原始資料不用隨 Git 專案上傳，但每次新增資料仍需要在有 Node.js 的電腦上執行轉換。GitHub Pages 不會在瀏覽器內自動轉換 ZIP。
